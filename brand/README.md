# ZNK 品牌标识（T-0805）

> 唯一副本：`E:\ai-crew-assets\znk-mcp\brand\`（另有 `MANIFEST.sha256`）。
> 生成脚本：`scripts/make_brand.py`（Pillow 12.3.0，纯几何绘制，可复现）；校验脚本在班组侧 `下属14\brandgen\verify_brand.py`。
> 生成日期：2026-11-24。全部图形为本单原创几何，**不含任何第三方素材/字体/图标/人脸/商标**。

## 1. 文件与用途

| 文件 | 尺寸 | 格式 | 用途 |
|---|---|---|---|
| `logo-400x400.png` | 400×400 | PNG 8-bit RGB，无 alpha | Cline MCP Marketplace 提交要求的主 logo；Glama 条目图；文档头图 |
| `logo-1024.png` | 1024×1024 | PNG 8-bit RGB，无 alpha | 高清/印刷/演示、README 大图、社媒头像母版 |
| `favicon-32.png` | 32×32 | PNG 8-bit RGB，无 alpha | 站点 favicon（**光学变体**：只保留立方标，去掉文字，线宽加粗，见 §4） |
| `apple-touch-icon-180.png` | 180×180 | PNG 8-bit RGB，无 alpha | iOS 主屏图标 / PWA 图标 |
| `logo.svg` | viewBox `0 0 400 400` | SVG 1.1，纯矢量 | 可编辑母版：改色、缩放、拆图层、做深/浅底变体 |
| `MANIFEST.sha256` | — | 文本 | 本目录全部文件的 SHA256，便于校验唯一副本 |

## 2. 色值

| 名称 | HEX | RGB | 用途 |
|---|---|---|---|
| 深底 Ink | `#0B0F14` | 11,15,20 | 所有 PNG 画布底色（不透明，不依赖页面背景） |
| 品牌青 Cyan | `#22D3EE` | 34,211,238 | 立方线框外轮廓（六边形剪影）；唯一强调色 |
| 白 White | `#FFFFFF` | 255,255,255 | 立方体三条可见内棱 + `ZNK` 字标 |

配色只有 3 个实色，**无渐变、无噪点、无阴影、无发光**；PNG 只有抗锯齿产生的过渡像素（400px 版 833 色，1024px 版 648 色）。

## 3. 设计规格（与 `logo.svg` 一一对应）

- 立方线框：等轴测六边形剪影（中心 `200,154`，外接半径 `98`），外框青 `#22D3EE`、线宽 `6`（400 坐标系）；三条可见内棱白 `#FFFFFF`，同线宽，笔端为平头、拐点为圆角；青色外框后绘，压住白棱端头，保证轮廓干净。
- 字标：`ZNK`，三个几何字母（Z/N/K）由矩形与平行四边形拼成，**不是字体**，可直接编辑路径；字高 52、字宽 42、笔画 11、字距 16，字标区 `y=292..344`，水平居中。
- 版式：上立方（`y=56..252`）+ 下字标（`y=292..344`），上下留白各 56，视觉居中。
- 明暗对比：白字对深底对比度 ≈ 19.2:1，青对深底 ≈ 10.6:1（WCAG 2.x 相对亮度公式，sRGB），均过 AA/AAA 正文级。

## 4. 小尺寸规则（重要）

- **≥48 px**：用 `logo.svg` / `logo-1024.png` / `logo-400x400.png`（完整版，含字标）。
- **≤47 px**：用 `favicon-32.png` 的构图规则——只留立方标、线宽按像素加粗（32px 时线宽约 1.7px），字标在该尺寸下会糊成一团，故不出现。它是同一立方几何的光学变体，不是另一个标志。
- 需要 16/48/96 等多尺寸 ICO 时，从 `logo.svg` 的「只留立方」变体导出，不要用 32px 位图放大。

## 5. 允许用途

- `znk-mcp` 的 npm/GitHub 文档、README、发布说明、演示文稿、官网/落地页的标识。
- 提交到 Cline MCP Marketplace（400×400 要求）、Glama、mcpservers.org 等目录的服务条目图。
- 站点 favicon、PWA/iOS 图标、应用内「关于」页。
- 新闻稿、第三方评测中**原样引用**本标识（不修改、不拉伸）。

## 6. 禁止用途

- 禁止改色、加渐变/阴影/发光/描边特效、旋转、拉伸变形、裁切、局部遮挡、加文字或水印后仍称「ZNK 官方标识」。
- 禁止在标识上叠加人脸、商标、二维码、第三方图标；禁止与其它 logo 拼接成联合标志。
- 禁止用本标识暗示 ZNKernel-II / znk-mcp 对第三方产品的认证、背书、合作或隶属关系（未经书面授权）。
- 禁止把本标识注册为商标、外观设计或作为自有商标使用（商标权属另议，本单只交付图形文件）。
- 禁止单独把 `#0B0F14` 深底去掉后放到浅色/花哨背景上使用（对比度会失效）；需要浅底版时从 `logo.svg` 反色重制，不要改 PNG。
- 禁止把 32px 位图当母版放大，或把 `logo.svg` 的字母路径当字体文件分发。
